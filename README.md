# הקופה שלי

מערכת קופה וירטואלית חינוכית לילדים בגילאי 5–10.

## עקרונות
- שלוש קופות בלבד: הוצאות, חיסכון ותרומה.
- אין כסף אמיתי, סליקה, בנק או העברות פיננסיות.
- יתרות מחושבות מיומן תנועות בלתי ניתן לעריכה.
- עברית מלאה, RTL, וממשקים נפרדים לילדים ולהורים.

## מבנה מתוכנן
- `apps/web` — אפליקציית React.
- `apps/api` — API ב-Node.js.
- `packages/domain` — לוגיקת מוצר טהורה.

## פיתוח
הוראות התקנה והרצה יתווספו עם שלד הפרויקט.

## אבטחה
אין לשמור סודות או קובצי `.env` בריפו. יש להשתמש ב-`.env.example` לערכי דוגמה בלבד.
